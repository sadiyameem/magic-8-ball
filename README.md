# Magic 8 Ball

# Description
- This is a simple magic 8 ball where users can type a question and click the ball to get an answer.

# Features
- Magic 8 Ball
- Question input
- Random answer
- Rotating ball when clicked
- Answer appears after ball is clicked

# Tools
- HTML
- CSS
- JavaScript
- https://emojicopy.com/

# Challenge/Learned
- I struggled with adding a theme switcher even though I didn't end up using it I still struggled with adding it and making it work.
- I learned how to use elements, event listeners to respond to user inputs.
